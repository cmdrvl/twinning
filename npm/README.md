# @cmdrvl/twinning-mcp

MCP server for [twinning](https://cmdrvl.com/twinning/), an open-source tool that
makes a protocol contract runnable. It serves local twins of Postgres, REST, and
Snowflake contracts so agents and test suites never touch production.

This package is a launcher: it runs the `twinning-mcp` binary from the matching
GitHub release.
